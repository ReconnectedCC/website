Install Instructions

1. Download the pack with the button below. We suggest the modern pack.

2. Open Prism Launcher or compatible launchers and click on "Add Instance".

3. Click "Import" and choose the downloaded pack.


The difference between the beta and classic packs is that the beta pack uses
the unsup updater, which has better UX and is newer, while the classic
pack uses the original packwiz updater.


Both will download the same modpack, use the other option if you are having issues.
